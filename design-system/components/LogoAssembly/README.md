Animação de assinatura: as seis peças reais do logo (I, L, Y em duas partes, T em duas partes) chegam carregadas por cursores e se encaixam.

- Usar uma vez: no carregamento da página (intro curta) ou no rodapé.
- Cada peça: deslocamento + rotação leve, `dur-slow` com `ease-snap`, 260ms entre peças.
- Cursores em `amber` com etiquetas `design`, `código`, `dados`: as três frentes da fábrica.
- Com `prefers-reduced-motion`, o logo aparece já montado.
- No site final, os recortes passam a usar o SVG oficial (cada peça um `<path>`).
