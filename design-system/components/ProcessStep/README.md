Etapas do processo de trabalho em sequência numerada; a numeração é real (ordem das etapas).

- Recebe: número, título (`h3`) e uma frase (`body`, `ink-muted`).
- Linha `line` no topo com um trecho de 40px em `amber` marcando a etapa; número em `code`/`amber`.
- No site, a linha âmbar avança com o scroll (ScrollTrigger) de uma etapa para a próxima.
- Use só para sequências reais. Para listas sem ordem, use ServiceCard.
