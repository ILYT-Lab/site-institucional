Abertura padrão de cada seção: rótulo, título e uma frase de apoio.

- Recebe: rótulo (`label`, maiúsculas), título (`h1`) e subtítulo opcional (`body-l`, `ink-muted`).
- O rótulo tem uma pequena peça `amber` de 24×8px antes do texto: o "encaixe" que abre a seção.
- Desktop: título à esquerda, subtítulo à direita, alinhados pela base. Celular: empilhado.
- Distância até o conteúdo: `space-12`.
- Número no rótulo só quando há sequência real (`4 etapas`), nunca decorativo.
