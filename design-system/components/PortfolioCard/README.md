Card de projeto do portfólio, com imagem da demo, nicho, tipo de solução, resultado e link para a demo ao vivo.

- Recebe: imagem (4:3), nicho, tipo de solução, título, uma frase de resultado e link (página do case ou `demo.ilyt.com.br/...`).
- Imagem em `radius-piece` com borda `line`; selo "Demo ao vivo" no canto quando houver demo.
- A frase conta a mudança na rotina do cliente ("pedidos que chegavam por áudio agora..."), não a tecnologia.
- Grade de 2 ou 3 colunas, gap `space-6`; no celular, uma coluna.
- Os projetos do preview são exemplos para mostrar o formato, não clientes reais.
